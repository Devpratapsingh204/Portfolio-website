## Run Locally

### Requirements

- Node.js (LTS recommended)
- npm

### Setup

```bash
git clone https://github.com/Devpratapsingh204/Portfolio-website.git
cd Portfolio-website
npm install
npm run dev
```

Vite will print the local development URL in the terminal.

### Production Build

```bash
npm run build
npm run preview
```

The production files are generated in the `dist/` directory.
