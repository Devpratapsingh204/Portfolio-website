# Dev Pratap Singh — Portfolio

Premium, responsive portfolio built with **HTML, CSS and JavaScript** using Vite. No React or other UI framework is required.

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL.

## Production build

```bash
npm run build
npm run preview
```

## Content source

Portfolio facts were based on the supplied CV and certificate images. The core featured projects are the three projects listed in the latest CV. Other GitHub repositories can be added later without changing the visual system.

## Important

- Replace any placeholder/temporary GitHub URL in a project card with the exact repository URL if you want a project-specific link.
- The CV is included at `public/Dev_Pratap_Singh_CV.pdf`.
- Certificate images are included under `src/assets/`.
